## 이 시안에 대하여

`홈페이지2(데스크톱)` 프로토타입(예매 포털형)의 **톤** — navy+gold 팔레트, 카드형 검색
패널, 뮤트 그라데이션 플레이스홀더 — 만을 frontend-v2의
**도구형 홈 구조**에 적용한 적용안 시안이다.

큐레이션 섹션(인기 공연·카테고리·지역별·예매 랭킹·티켓 오픈 예정)은 데이터 원천이 없어
**제외 확정**되었으며, 검색 패널 바로 아래에 공연 목록이 곧 메인 콘텐츠로 노출된다.
"있어 보이는 가짜 데이터"를 넣지 않는 기본 원칙(적용-검토사항 0절)을 따른다.

### 카드 4건의 역할 (표기 규칙 시연)

1. **1번 카드** — 검색어 일치 곡 메인 표시(search-008), `(외 N곡)` hover flyout(card-010),
   오류 제보 버튼
2. **2번 카드** — 포스터 `null` → **뮤트 그라데이션 + 라인 아이콘 공식 fallback**(신규 채택 제안),
   하루 복수 회차(card-019)
3. **3번 카드** — 복수 작곡가 프로그램 표기(card-011) + 검색어 일치 곡 메인 표시(search-008)
4. **4번 카드** — 다곡 단일 작곡가 프로그램(전주곡·에튀드 등 11곡): flyout 최대 높이 초과 시
   목록 스크롤 + 스크롤 중 작곡가 그룹 헤더 고정(sticky) 시연. 포스터 더미 변형 톤(p2), 단일 회차 표기.

## 이 시안이 '제안'하는 미결 사항 (승인 필요 — 적용-검토사항 8절)

1. **검색 패널 구성**: 기존 2단 구조(히어로+검색바 / 상태+기간 바)를 → 패널형
   (검색어 + 관람 기간 2필드)로 통합 제안. 기간 선택은 기존 DateRangePicker(달력+프리셋)를
   패널 필드 클릭 시 팝오버로 노출하는 형태. 상태 탭은 패널 하단 툴바로 이동 (search-004
   "검색 ui 하단" 유지).
2. **폰트**: ✅ 확정 (2026.10.23) — 한글은 Pretendard(산세리프)로 통일하고, **영문 디스플레이는
   Josefin Sans로 통일**(로고, 포스터 더미 텍스트, 영문 곡명, PROGRAM/ARTISTS 라벨,
   flyout 번호 등). 초기 시안의 Noto Serif KR은 로드 실패 시 궁서체 계열 시스템 세리프로
   폴백되는 문제가 있어 제외했고, 이후 Playfair Display도 Josefin Sans로 교체했다.
   구현 시 `next/font/google`의 Josefin_Sans 추가 필요.
   ※ 히어로의 'Classical Repertoire Index' 키커도 2026.10.23 제거 확정.
3. **색**: navy/gold 팔레트를 신규 톤으로 채택 제안. 단 gold는 강조(라벨·숫자·언더라인·
   배지·hover)로 제한하고, 본문 텍스트에 gold를 쓰지 않음. 검색/예매 버튼의
   "hover 시 gold 배경 + 남색 글자" 패턴은 대비비(WCAG AA) 실측 후 확정.
4. **아이콘**: 라인 SVG 소수(검색·달력·새로고침·악보·깃발·핀·티켓 등)만 Icon 컴포넌트에
   추가 제안. 카테고리 악기 아이콘 세트는 카테고리 기능이 없어 불요.
5. **카드 hover `translateY(-6px)`**는 앨범형에만 적용(적용-검토사항 3절 방침). 리스트형은
   gold 보더 강조만.
6. **검색 버튼 hover gold 배경 + 남색 글자 패턴**: 접근성 대비비 실측 후 확정 (검토사항 5절).
6. **곡 카드 radius**: 프로토타입의 16px 대신 기존 디자인 시스템의 건축적 micro-radius(4~6px)
   유지. 패널 top-radius(18px)만 시그니처로 유지.
7. **카드 메타 섹션**: ✅ 확정 (2026.10.23) — 러닝타임·관람연령·공연 장소·좌석별 티켓 가격
   블록은 공연 카드에서 제외. 현행 specs card-012/013/014는 카드 표기 규칙이므로
   구현 시 정책 갱신을 먼저 진행할 것.
8. **모바일 보기 모드**: ✅ 확정 (2026.10.23) — 모바일에서는 보기 모드 토글을 노출하지 않고
   앨범형(포스터 상단 카드)으로 고정 (specs view-003과 동일 방침).
9. **추천 검색어 칩**: ✅ 확정 (2026.10.23) — 검색 패널에서 제외. 인기 검색어 집계
   (PostHog `search` 이벤트)가 충분해지면 그때 재검토.
10. **프로그램 표기 방식**: ✅ 확정 (2026.10.23) — 카드에는 일치 곡(search-008, 무검색 시
    첫 곡) 1곡만 메인 표시 + `(외 N곡)`. 곡 수 편차가 커서(리사이틀 8~12곡, 오페라 3막
    전체 등) 전체 펼침은 카드 높이 불균일·스캔성 저하를 유발하기 때문. 상세는 데스크톱
    hover flyout(card-010) / 모바일 '전체 프로그램 보기' 터치(card-009)로 확인한다.
    시안 반영: 모바일 전용 진입점 버튼, `(외 N곡)` hover 힌트(gold 점선 밑줄 + chevron),
    모바일에서는 `(외 N곡)`을 단순 표기로 강등.

## 샘플 데이터에 대하여

카드의 공연명·연주자·가격은 **표기 규칙 시연용 가상 데이터**이며 실존 공연이 아니다.

- 프로그램 영역 hover 시 flyout은 리스트형과 동일한 인터랙션(view-004). 카드 폭이 좁으므로
  flyout은 '외 N곡'이 속한 프로그램 박스 바로 하단에 카드 폭으로 펼친다(z-40, card-010 규칙 준수).
  카드 hover 리프트 시 flyout이 인접 카드 위에 그려지도록 hover 카드만 로컬 스택 맨 위로 올린다.
- 카드에 담는 정보는 리스트형과 동일하다(러닝타임·관람연령·좌석 가격 등 제외 확정 항목 미포함).
  아티스트·주소는 카드 폭 특성상 1줄 말줄임. CTA(예매처 바로가기)는 카드 하단 풀폭 버튼.
- 결과 헤더의 '한 페이지에 최대 N건' 안내는 미노출한다(2026.10.28) — specs search-006
  페이지당 건수 표기 정책과 어긋나므로 구현 전 갱신 검토 대상.
- 검색 패널의 **관람 기간 필드 클릭 시 기간 선택 popover**가 열린다 — `기간 선택 ui(데스크톱)`
  시안을 적용안 톤으로 이식(기간 프리셋 + 2개월 달력 + 적용/초기화, 공연 있는 날 dot 표시).
  범위 밖 날짜는 비활성(exception-02 clamp), 새로고침 버튼은 search-005대로 최대 기간 초기화.
- **정렬 기준은 드롭다운**으로 동작한다 — 구 시안(홈페이지(데스크톱))의 정렬 3종
  (공연임박순·낮은 가격순·높은 가격순). 가격순은 카드 가격 표기 제외 정책과 별개 항목이므로
  가격 데이터 원천 확정 시 재검토.

### 전체 프로그램 flyout — 작곡가별 그룹핑 (2026.10.27, 리스트형·앨범형 공통)

hover flyout의 곡 목록은 **작곡가별로 그룹핑**해 표시한다. 한 작곡가가 여러 곡을 연주하는
프로그램에서 작곡가명이 매 줄 반복되는 것을 없애고 스캔성을 높인다.

- 그룹 헤더: 작곡가 이름(굵게) + 곡 수(`N곡`)
- 곡명은 `작곡가 - ` 접두 없이 표기 (그룹 헤더가 작곡가 맥락을 제공)
- 각 곡의 **영어 원제를 한글 제목 아래 병기**한다 — 카드 메인 표시의 영문 곡명(p-en)과
  동일 톤(Josefin Sans 이탤릭, 뮤트)으로 톤을 통일한다 (2026.10.27)
- 번호(1, 2, 3…)는 그룹을 넘어 연속 부여해 실제 연주 순서를 나타낸다
- 검색어 일치 곡(search-008)은 flyout 안에서도 gold 언더라인으로 표시해 카드 메인 표시와 연결한다
- 곡 수가 많은 프로그램(리사이틀 등)에서는 목록 영역 높이를 최대 320px로 제한해 그 영역만 스크롤한다 —
  flyout 헤더(전체 연주 프로그램·러닝타임)는 항상 고정되고, 스크롤 중에는 현재 작곡가 그룹 헤더도
  함께 고정(sticky)된다. 휠 스크롤이 flyout 안에서 멈추도록 overscroll-behavior를 contain으로 둔다.
  시연은 4번 카드.
- **카드의 '프로그램 작곡가' 요소는 제거**했다(2026.10.28) — 작곡가 정보는 flyout의 작곡가 그룹
  헤더로 흡수된다. specs card-007('프로그램 작곡가:' 라벨 관련 문구)는 구현 전 삭제·갱신이 필요하다.

이는 specs에 없는 표기 제안이므로, 구현 시 specs card-010 갱신과 함께 검토할 것
(card-010은 flyout의 위치·z-index만 규정하므로 그룹핑·스크롤과 충돌하지 않는다).

## 모바일 (뷰포트 ≤760px) — view-003

모바일은 별도 파일 없이 위 화면의 **반응형 렌더링**으로 대응한다(2026.10.28 —
뷰포트를 줄일 때 나타나는 디자인이 곧 모바일 시안). 전체 모습은 `screen-mobile.png` 참조.

- 앨범형(index-album.html) 기준: 보기 모드 seg 미노출(view-003), 검색 패널 세로 스택,
  카드 1열(포스터 최대 320px 중앙), 카드에 '전체 프로그램 보기' 버튼 노출(card-009 —
  시트는 `전체 프로그램 바텀시트(모바일)/`), 관람 기간 필드 클릭 시 모바일 기간 선택 시트
  (`기간 선택 ui(모바일)/`)가 열린다.
- 리스트형(index.html)도 같은 규칙으로 1열 스택을 지원한다(참고용 — 실제 모바일은 view-003에
  따라 앨범형 구조).
- 카드 그리드 아이템에 `min-width: 0`을 적용해 390px 폭에서 가로 스크롤이 생기지 않으며,
  아티스트명·주소는 말줄임 처리된다(390px 실측).
