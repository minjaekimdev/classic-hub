## 이 시안에 대하여

모바일 검색 패널의 관람 기간 필드를 눌렀을 때 나타나는 기간 선택 바텀시트 시안이다.
데스크톱 popover(홈페이지 수정안/index-album.html)와 동일 구성을 모바일 시트 형태로 재구성했다.

## 구성과 specs 대응

| 영역 | 내용 | specs |
|---|---|---|
| 헤더 | '관람 기간' + 닫기 버튼, 상단 grabber | — |
| 범위 안내 | '최대 3개월 탐색' 칩 + 조회 범위 설명 | — |
| 기간 프리셋 | 이번 달 / 향후 1개월 / 향후 3개월 전체 — 세로 라디오 리스트(선택 표시) | — |
| 달력 | 1개월 단위 + 이전/다음 달 이동. 탐색 범위 밖 날짜는 비활성(exception-02 clamp), 선택 시작일은 navy, 범위 내는 gold-tint, 공연 있는 날은 dot | — |
| 액션 | 초기화 (3개월) / 적용하기 | search-005 |

## 정책 메모

- 새로고침 버튼(검색 패널 필드 우측)과 '초기화'는 모두 탐색 가능한 최대 기간으로 되돌린다(search-005).
- 프리셋의 범위 표기(예: 이번 달 = 10. 23 ~ 10. 31)는 탐색 시작일로 clamp한 결과를 미리 보여준다(exception-02).
- 데스크톱(2개월 달력 popover)과 모바일(1개월 달력 시트)이 동일한 프리셋·범위 규칙을 공유한다.
- 구 시안 `기간 선택 ui(모바일)/`를 대체한다.
