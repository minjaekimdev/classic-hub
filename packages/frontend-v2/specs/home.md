## 공통

- common - 001: 공연 상태는 ‘공연중’, ‘공연 예정’ 2가지만 표기한다. (데스크톱, 모바일)

## 헤더

- head - 001: 헤더 우측에는 향후 탐색 가능한 기간을 출력한다.

## 검색

- search - 001: 검색 input의 placeholder는 실제 가능한 검색어 예시만을 표시한다. (데스크톱, 모바일)
- search - 002: 검색 시 일치하는 공연은 프로그램 > 공연명 > 아티스트명 순으로 찾는다.
- search - 003: 옵션은 ‘공연임박순’, ‘낮은가격순’, ‘높은가격순’ 3가지이며, 이 문구를 포함한 네모 박스 영역이라면 아무곳이나 클릭해도 옵션 선택 ui가 하단에 나타난다. 이 때 옵션 선택 ui와 드롭다운 트리거 ui의 오른쪽 모서리는 일직선상에 존재한다. (데스크톱, 모바일)
- search - 004: 검색 ui 하단 '전체', ‘공연중’ 공연예정’ 버튼의 문구 오른쪽의 괄호에는 해당 상태에 맞는 공연의 개수를 출력한다. (데스크톱, 모바일)
- search - 005: 공연 기간 선택 ui 우측에 있는 새로고침 버튼을 누르면 탐색 가능한 최대 기간으로 초기화된다. (데스크톱, 모바일)
- search - 006: 검색 결과는 한 페이지에 최대 5개까지 보여준다. (데스크톱, 모바일)
- search - 007: 검색 결과 ui에서 '검색 필터 초기화' 버튼을 누르면 설정한 검색어와 공연상태, 공연기간, 정렬기준이 모두 초기화된다.
- search - 008: 검색어로 검색 시 해당 검색어와 작곡가/곡명이 일치하는 프로그램이 있다면, 해당 작품을 공연 카드의 프로그램 영역에 메인으로 보여준다.


## 공연 카드

- card - 001: 공연 포스터는 세로 중앙 정렬한다. (데스크톱)
- card - 002: 공연 포스터가 들어가는 영역의 크기는 모두 동일하다. 가로 세로 비율을 맞추어 영역에 포함시킨다. (모바일)
- card - 003: 장소 첫 줄에는 홀 이름, 두 번째 줄에는 상세 주소를 명시한다. (데스크톱)
- card - 004: 공연 날짜는 첫째 줄, 공연 요일 및 시간은 둘째 줄에 표기하며, 당일 공연의 경우 ~로 표기하지 않고 하나의 날짜만 표기한다. (데스크톱, 모바일)
- card - 005: 아티스트 라벨과 아티스트명은 한줄에 배치하고, 아티스트가 많아서 줄바꿈이 되는 경우 라벨과 아티스트명을 별도의 줄로 두지 않고 그대로 줄바꿈한다. (데스크톱)
- card - 006: 아티스트 라벨과 아티스트명을 별도의 줄에 배치한다. (모바일)
- card - 007: ‘프로그램 작곡가’ / 아티스트가 없을 경우 해당 ui는 전부 보이지 않는다. ”프로그램 작곡가: “ 라는 라벨도 보이지 않고, 해당 영역을 전부 제거한다. (데스크톱, 모바일)
- card - 008: 프로그램을 표기할 때는 한글 제목과 영문 제목은 무조건 줄바꿈으로 구분되어야 한다. (… 외 N곡)은 곡명과는 별도의 영역으로 관리되며, 줄바꿈에 포함되지 않고, 항상 첫 줄에 표기한다. 제목이 길어 줄바꿈이 필요하다면 곡명 영역 안에서만 줄바꿈한다. (데스크톱, 모바일)
- card - 009: ‘전체 프로그램 보기’ 버튼을 누르면 상세 곡을 볼 수 있는 바텀시트가 나타난다 (모바일)
- card - 010: 프로그램 영역을 hover하면 상세 곡을 볼 수 있는 별도의 ui가 뜬다. 이 때 해당 ui는 `외 N곡` ui 바로 하단으로 위치가 고정된다. 또한 z-index는 공연 카드보다 높아야 하고, 헤더보다 낮아야 한다. (데스크톱)
- card - 011: 작곡가를 표기할 때는 한 줄에 배치한다. 작곡가가 많아 줄바꿈이 필요해도 라벨(`프로그램 작곡가:`) 과 작곡가명이 별도의 줄로 분리되지 않는다. (데스크톱, 모바일)
- card - 012: 러닝타임 / 관람연령 / 공연 장소가 없는 경우 ‘-’ 문자를 표기한다. (데스크톱, 모바일)
- card - 013: 티켓 가격이 무료라면 ‘전석 무료’, 가격 정보가 제공되지 않는다면 ‘가격 정보가 제공되지 않습니다’ 표기 (데스크톱, 모바일)
- card - 014: 좌석별 티켓 가격이 아직 없는 경우 해당 영역을 제거한다. (데스크톱, 모바일)
- card - 015: ‘<예매처> 공식 티켓 예매’ ui에는 중 티켓 링크 중 가장 최상단의 요소를 넣는다. (데스크톱, 모바일)
- card - 016: ‘예매처 바로가기’ 클릭 시 티켓 링크 중 가장 최상단의 링크로 이동한다. (데스크톱, 모바일)
- card - 017: 공연장 상세 주소가 제공되지 않는 경우 해당 영역을 아예 없앤다.
- card - 018: 프로그램 영역의 곡 제목은 '라흐마니노프 - 피아노 협주곡 3번'과 같이 '작곡가 - 곡명' 형식으로 작성한다.
- card - 019: 공연 일시가 하루에 여러 개의 시간대가 있을 경우 `토요일(14:30,17:00,18:00), 일요일(14:30,17:00), 수요일(18:00,20:00)`와 같은 형식으로 표시한다.

## 피드백

- feedback - 001: ‘서비스 의견 보내기’ 버튼을 누르면 피드백을 보낼 수 있는 모달 창이 등장한다. (데스크톱)
- feedback - 002: ‘피드백’ 버튼을 누르면 피드백을 보낼 수 있는 바텀시트가 등장한다. (모바일)

## 예외 처리

- exception - 01: 사용자가 /asdf를 치거나 공유된 링크가 자체가 잘못된 경우에는 app/not-found.tsx 라우팅으로 처리한다.
- exception - 02: url에 지정된 기간을 벗어나는 날짜가 파라미터로 들어가거나 ?page=99999같이 존재하지 않는 페이지를 요청하는 경우에는 유효 범위로 clamp한다. 이외에는 app/not-found.tsx 라우팅으로 처리한다
- exception - 03: 조건에 맞는 공연이 없을 때는 no-result ui를 보여준다.
- exception - 04: 짧은 시간에 너무 많은 요청이 들어올 경우에 대비하여 요청에 500ms 디바운싱을 지정한다.
